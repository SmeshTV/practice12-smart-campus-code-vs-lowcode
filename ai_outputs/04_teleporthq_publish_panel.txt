Read against the requirement sheet, these lines decide four things:

1. The submission asks for a live demo link. The link exists, and the same panel says every visitor must also be
   given a six-character password that cannot be removed on this plan. The demo is therefore only as available as
   the mail that carries the password.
2. The generator created an admin panel and an authentication page that the contract never asked for, and the
   publish drawer offers to create the first admin user on the live deployment. Nothing was created, so the
   address is published with no owner and no key. It answers 401 behind the same wall, which is why this is a
   customization finding rather than an incident, and it is exactly the kind of surface a visual builder hands
   you without being asked.
3. "1 services need credentials configured: Resend" is the platform telling the student to paste an email
   provider API key into the project. No key was added, and the contract has no email step, so the app was left
   in the state the panel calls not set up. For the security checklist this is the connector question, and the
   answer is: the platform wants a credential, the student refused to add one, and the demo still satisfies the
   requirement sheet without it.
4. The panel measures page weight itself and warns above 170 kB on phones. The code track's shipped bundle for
   the same feature is 158.95 kB (`index-Bp9-gzrV.js`), which sits just under the platform's own threshold and
   was written by hand rather than generated.

## 5. Docker and WSL, the self-hosting route

```
$ docker version
/usr/bin/bash: line 1: docker: command not found

$ wsl -d Ubuntu -u root -- bash -lc "which docker && docker version"
WSL2 не поддерживается текущей конфигурацией компьютера.
Включите дополнительный компонент "Платформа виртуальной машины" и включите виртуализацию в BIOS.
Чтобы включить компонент "Платформа виртуальной машины", выполните команду wsl.exe --install --no-distribution
Дополнительные сведения см. на странице https://aka.ms/enablevirtualization
Код ошибки: Wsl/Service/CreateInstance/CreateVm/HCS/HCS_E_HYPERV_NOT_INSTALLED
(exit code 127)

$ wsl -l -v
    NAME      STATE           VERSION
*   Ubuntu    Stopped         2
```

Re-run 25 November 2026 from this session. The block is quoted in the language the machine answers in. In English it
says WSL2 is not supported by the current configuration of the computer, that the "Virtual Machine Platform"
optional component must be enabled and virtualisation turned on in the BIOS, and ends with the code
`HCS_E_HYPERV_NOT_INSTALLED`. The distro is registered as version 2 but cannot boot, so no container starts on
this laptop and a self-hosted Appsmith or Budibase is not available to this student either.
